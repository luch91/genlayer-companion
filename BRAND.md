# Brand decision — Builder Companion

## Selected mark: Field Note

Selected on 20 August 2026.

The Field Note mark is a connected set of seven tiles that converge around a shared core. It represents the ecosystem surrounding a builder: ideas, learning, contributions, missions, tools, community, and the product itself. It is intentionally human and editorial rather than using familiar AI, crypto, or handshake symbolism.

### Core palette

| Role | Colour | Hex |
| --- | --- | --- |
| Ink | Deep teal | `#082E38` |
| Signal | Terracotta | `#E76F51` |
| Network | Powder blue | `#9ED4E2` |
| Foundation | Warm cream | `#F3E9D2` |

### Usage

- Use the full-colour mark on dark or light neutral backgrounds.
- Keep all tiles and connectors flat; do not add gradients, glow, or shadows.
- Preserve clear space equal to one tile width around the mark.
- Use the mark alone for app icons and favicons; pair it with the Builder Companion wordmark in navigation and marketing contexts.
